# Dynamic Island: Dot Settlement & Compound Motion Fix

Rencana eliminasi efek "dot meluncur patah/kebut" saat musik berhenti dengan memisahkan animasi penyusutan lebar kapsul dari pergeseran anchor ikon[cite: 2].

---

## 1. Akar Masalah (Root Cause)

- **Compound Motion Collision**: Kapsul menyusut lebarnya menuju pusat (`island.horizontalCenter`), sementara di waktu yang sama `statusIconContainer` menjalankan `AnchorAnimation` dari sisi kiri (`island.left`) menuju tengah (`island.horizontalCenter`)[cite: 2]. Kedua vektor gerak ini saling berlipat ganda, menghasilkan ilusi ikon meluncur terlalu kencang dan tersentak saat mendarat[cite: 2].
- **Glyph Switch Prematur**: Karakter teks berubah dari `󰎈` menjadi `●` pada fase 1 (`mediaTextCollapsed = true`, 260ms) saat pergerakan kapsul belum rampung, menyebabkan _visual pop_[cite: 2].
- **Desinkronisasi Phase Timer**: Durasi penyusutan kapsul adalah `400ms`, tetapi `mediaStopPhase2Timer` melepaskan state pada `360ms`, membuat transisi terpotong sebelum kurva deselerasi selesai[cite: 2].

---

## 2. Rencana Implementasi

### Langkah 1: Kunci Posisi Anchor Ikon Selama Kapsul Menyusut

- **Target**: `DynamicIsland.qml` -> `Rectangle#island` -> `Item#statusIconContainer` -> `states` (`State: ICON_LEFT`)[cite: 2]
- **Tindakan**:
  - Ubah kondisi `when` pada `ICON_LEFT` agar menahan anchor tetap di kiri selama seluruh proses `root.mediaStopping` berlangsung:
    ```qml
    State {
        name: "ICON_LEFT"
        when: !Services.OverlayManager.isLocked && (root.showCollapsedText || root.mediaStopping)
        AnchorChanges {
            target: statusIconContainer
            anchors.horizontalCenter: undefined
            anchors.left: island.left
            anchors.right: undefined
        }
        PropertyChanges {
            target: statusIconContainer
            anchors.leftMargin: 12
        }
    }
    ```
  - Efek: Ikon tetap stabil di sisi kiri saat tepi kiri kapsul menyusut ke dalam. Tidak ada gaya gerak ganda.

---

### Langkah 2: Tahan Bentuk Glyph Musik Sampai Kapsul Berhenti

- **Target**: `DynamicIsland.qml` -> `Rectangle#island` -> `Item#statusIconContainer` -> `Text#statusIconTxt`[cite: 2]
- **Tindakan**:
  - Jangan ganti ikon ke `●` saat teks hilang[cite: 2]. Pertahankan `󰎈` selama `mediaStopping` aktif:
    ```qml
    text: {
        if (Services.OverlayManager.isLocked) return "󰌾"
        if (root.notifActive) return "󰂚"
        if (root.mediaPlaying || root.mediaStopping) return "󰎈"
        return "●"
    }
    ```
  - Ikon hanya akan berubah menjadi dot idle setelah kapsul selesai menyusut sempurna.

---

### Langkah 3: Sinkronisasi Interval Timer dengan Durasi Animasi

- **Target**: `DynamicIsland.qml` -> `Timer#mediaStopPhase1Timer` & `Timer#mediaStopPhase2Timer`[cite: 2]
- **Tindakan**:
  - Sesuaikan interval agar berurutan secara sequential tanpa overlap kasar:
    - `mediaStopPhase1Timer.interval = 220` (Memberi waktu teks & visualizer larut memudar duluan)[cite: 2].
    - `mediaStopPhase2Timer.interval = 400` (Menyesuaikan tepat dengan durasi `Behavior on width: 400ms`)[cite: 2].

---

### Langkah 4: Redam Transisi Anchor Menuju Tengah

- **Target**: `DynamicIsland.qml` -> `Rectangle#island` -> `Item#statusIconContainer` -> `transitions`[cite: 2]
- **Tindakan**:
  - Karena pergeseran anchor baru terjadi saat kapsul sudah berukuran kecil (140px), jarak tempuh anchor tinggal sedikit (~20-30px).
  - Gunakan transisi halus tanpa overshoot:
    ```qml
    Transition {
        from: "ICON_LEFT"; to: "IDLE_CENTER"
        AnchorAnimation { duration: 320; easing.type: Easing.OutCubic }
        NumberAnimation { properties: "anchors.leftMargin"; duration: 320; easing.type: Easing.OutCubic }
    }
    ```

---

## 3. Alur Visual Akhir (Timeline)

1. **$t = 0\text{ ms}$ (Pause Ditekan)**: Musik berhenti[cite: 2]. Visualizer dan judul lagu langsung _fade + scale down_ ke dalam kapsul (selesai dalam ~220ms)[cite: 2].
2. **$t = 220\text{ ms}$**: Teks bersih lenyap. Kapsul mulai menyusut dari lebar lagu (~220px) ke lebar normal (140px) selama 400ms[cite: 2]. Posisi ikon tetap diam di kiri kapsul tanpa bergeser sendiri.
3. **$t = 620\text{ ms}$**: Kapsul telah mencapai ukuran 140px dan berhenti bergerak sepenuhnya.
4. **$t = 620\text{ ms} - 940\text{ ms}$**: Ikon berganti mulus menjadi dot `●` dan bergeser santai ke titik tengah (`IDLE_CENTER`), menghasilkan landing yang tenang tanpa loncatan.
